# John Alday - Project Portfolio Page

## Overview

TripJio is a command-line budget tracker and travel app for students. My work focuses
on shared bills, personal shares, participant debts and repayments.

## Summary of Contributions

- Extended shared bills with named participants and payers, debt queries, full and
  partial settlements, personal-share edits, and foreign-currency splits
  ([PR #15](https://github.com/AY2627S1-CS2113-W10-1/tp/pull/15)).
- Documented shared-bill design and commands in the Developer Guide and User Guide,
  including editable UML diagrams, storage compatibility and manual acceptance checks
  ([PR #23](https://github.com/AY2627S1-CS2113-W10-1/tp/pull/23)).
- Fixed foreign-split half-cent conversion using decimal rounding, with regression
  tests for amounts, participant debt and restart persistence
  ([PR #24](https://github.com/AY2627S1-CS2113-W10-1/tp/pull/24),
  [issue #58](https://github.com/AY2627S1-CS2113-W10-1/tp/issues/58)).
